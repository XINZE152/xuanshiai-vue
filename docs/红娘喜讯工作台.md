# 红娘喜讯工作台（GOOD-NEWS-20261104）

红娘管理中心使用 `MatchmakerGoodNews.uvue`，接口封装为 `api/workspace-good-news.uts`；与用户端已有的 `GoodNewsPanel.uvue`、`api/good-news.uts` 分开，保留用户端功能。

- 七个进展分类和锦旗分类使用两行入口，提供列表、详情、图片预览、分页、空状态和失败重试。
- 反馈喜讯填写双方称呼、相识月份、进展、内容和照片，确认授权后提交待审；网络失败保留表单和同一次提交的幂等键。
- 锦旗提供生成、保存和上传待审入口，受赠红娘由后端按当前身份确定。
- 审核通过的喜讯可送祝福、查看真实祝福记录；每个账号对同一喜讯只计一次。
- 不修改页面路由和 manifest，不把接口失败伪装成本地成功。

后端契约见后端仓库 `docs/api/红娘喜讯完整流程.md`。远端尚未部署本次新增接口；本地测试数据不提交、不迁移。发布代码保留正式仓库的远端默认环境，当前工作区的本地开关不随本次提交。

验证：喜讯流程与用户端喜讯契约测试、资料完整度契约、牵线、约会和账号页面测试；后端隔离 MySQL 测试。HBuilderX 已生成微信小程序产物，模拟器检查了列表、详情、反馈和祝福弹窗。

待继续验收：锦旗画布预览与导出修改后的实际运行效果；真机完整流程。现有开发产物主包超过 2 MiB，`verify-mp-weixin.ps1` 返回失败；旧 `test-mock-system.js` 的六处断言也返回失败，不能宣称全量门禁通过。
